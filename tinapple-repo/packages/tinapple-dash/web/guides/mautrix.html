Pairing Your Chat Bridges

WhatsApp 1. Link WhatsApp via QR Code
1. In Element / Element X, open a Direct Message (Start Chat) with @whatsappbot:tinapple.local.
2. Send the message: login
3. The bot will reply with a QR code in the chat.
4. Open WhatsApp on your phone: Settings → Linked Devices → Link a Device and scan the QR code.
5. All your WhatsApp conversations and contacts sync directly into your unified Element X inbox. 
!wa login
# Or type "login" directly to @whatsappbot:tinapple.local
Instagram 2. Link Instagram Direct
1. In Element / Element X, open a Direct Message with @instagrambot:tinapple.local.
2. Send the message: login
3. Follow the interactive prompts in the chat to enter your Instagram handle and password (or approve the 2FA login prompt on your phone).
4. All your Instagram Direct messages and media sync directly into Element X. 
login
# Send "login" directly to @instagrambot:tinapple.local
Discord 3. Link Discord (User Puppeting or Bot)
1. In Element / Element X, open a Direct Message with @discordbot:tinapple.local.
2. For personal user account puppeting (bridging your own DMs and servers), send:
login-token <your_discord_user_token>
3. Or for bot bridging into shared rooms, send: login-bot <bot_token>.
4. Your Discord direct messages, friend chats, and server channels will appear in Element X. 
login-token YOUR_DISCORD_TOKEN
# Or type "help" to @discordbot:tinapple.local for all commands

Native Systemd Management

All services run natively on bare-metal Arch Linux under systemd with PostgreSQL storage:
# Check Matrix Homeserver status
systemctl status synapse.service

# Check Sliding Sync Proxy (Element X)
systemctl status matrix-sliding-sync.service

# Check WhatsApp, Instagram, and Discord Bridges
systemctl status mautrix-whatsapp.service mautrix-instagram.service mautrix-discord.service

# View live bridge logs
journalctl -u mautrix-whatsapp.service -f
journalctl -u mautrix-instagram.service -f
journalctl -u mautrix-discord.service -f
