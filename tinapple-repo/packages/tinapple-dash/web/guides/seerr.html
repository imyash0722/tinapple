💡 Zero-Storage Duplication with Hardlinks

All media downloads are saved in /srv/media/downloads and instantly hardlinked into /srv/media/movies or /srv/media/shows.

  • No double storage: Hardlinks point to the same filesystem inode on disk, taking 0 extra bytes.
  • Continuous seeding: qBittorrent can seed indefinitely while Jellyfin streams the file.
  • Automatic cleanup: You can delete from either location without corrupting the file.
